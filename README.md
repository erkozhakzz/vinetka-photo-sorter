## 🚀 Ключевые возможности

1. **Поддержка любых форматов списков:**
   - Microsoft Word (`.docx`), Excel (`.xlsx`, `.xls`), `.csv`, `.txt`.
   - Полное сохранение казахских символов (`ә, ғ, қ, ң, ө, ұ, ү, һ, і`).
   - Автоматическое отделение классных руководителей и учителей.
2. **Профессиональная работа с фотоархивами:**
   - Форматы: `.JPG`, `.jpeg`, `.png`, `.webp`, `.heic` и RAW (`.CR2`, `.CR3`, `.NEF`, `.ARW`, `.DNG`).
   - Сопоставление номеров кадров с лидирующими нулями без ограничений.
   - 100% неприкосновенность оригинальных файлов (только чтение и безопасное копирование).
3. **ИИ-детекция качества лиц (YuNet + OpenCV DNN):**
   - Автоматическая безопасная инициализация моделей в путях с кириллицей через зеркало `C:\ProgramData\VINETKA\models`.
   - Оценка резкости, ориентации лица и открытости глаз (5 лицевых ориентиров).
   - Интеллектуальная рекомендация лучшего кадра для портрета и групповых серий.
4. **Быстрый отбор коллажей (AI Bursts Clusterer):**
   - Автоматическая группировка серий снимков по временным интервалам и номерам кадров.
   - Фильтрация одиночных портретов (только кадры с 2+ людьми).
   - Живой прогресс-бар в интерфейсе.
5. **Экспорт портретов с разделением по полу:**
   - Опция (чекбокс) **«Сохранить отдельно мальчики или девчонки»** / **«Ұлдар мен қыздарды бөлек сақтау»**.
   - При активации: внутри папки `Порт` автоматически создаются папки `Мальчики` и `Девчонки`.
   - При отключении: все портреты сохраняются напрямую в `Порт`.
   - Сохранение состояния чекбокса в `localStorage`.
6. **Лицензирование и Telegram Бот:**
   - Встроенный QR-код и прямая кнопка перехода в бот для покупки лицензий: [https://t.me/vinetka_keys_kz_bot](https://t.me/vinetka_keys_kz_bot).
   - Отображение QR-кода в окне активации (`license.html`) и в модальном окне настроек (`index.html`).

## 📁 Структура проекта

```
vinetka-photo-sorter/
├── index.html                  # Главный интерфейс приложения
├── license.html                # Окно первичной активации лицензии
├── main.cjs                    # Основной процесс Electron (IPC, проводник, экспорт)
├── preload.cjs                 # Защищенный мост API (Context Isolation)
├── parser.cjs                  # Движок парсинга Word, Excel, CSV, TXT
├── build-asar.cjs              # Сборщик чистого продакшн app.asar
├── installer.iss               # Скрипт компилятора Inno Setup
├── test.cjs                    # Комплексный самоочищающийся тестовый набор (39 тестов)
├── run.bat                     # Запуск приложения в один клик
├── package.json                # Конфигурация проекта (версия 2.2.7)
├── qr_telegram.svg             # QR-код бота @vinetka_keys_kz_bot
├── models/                     # Нейросетевые модели ONNX (YuNet, GenderAge)
└── scripts/
    ├── face_quality_engine.py  # Python-движок классификации и кластеризации
    └── build_mac_release.py    # Сборщик релиза для macOS arm64
```

## 🛠 Запуск и разработка

### Требования
- Node.js 18+
- Python 3.10+ (с установленными `opencv-python`, `numpy`, `onnxruntime`)

### 1-Клик Запуск
Дважды кликните по файлу:
```bat
run.bat
```

Или из терминала:
```bash
npm install
npm start
```

### Запуск тестов
```bash
npm test
# или
node test.cjs
```

## 📦 Сборка дистрибутивов

### 1. Сборка `app.asar`
```bash
npm run pack-asar
```

### 2. Сборка установщика Windows (.exe)
```powershell
& "C:\Users\Ереке\AppData\Local\Programs\Inno Setup 6\ISCC.exe" installer.iss
```
Результат: `VINETKA-Photo-Sorter-Setup-2.2.7.exe` (~154 МБ)

### 3. Сборка для macOS Apple Silicon (.zip)
```bash
python scripts/build_mac_release.py
```
Результат: `VINETKA-Photo-Sorter-macOS-arm64.zip` (~111 МБ)
