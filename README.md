# 📸 VINETKA Photo Sorter (Windows Desktop)

Официальное приложение для студии **VINETKA.KZ** для быстрой автоматической и полуавтоматической сортировки школьных и выпускных фотографий.

## 🚀 Возможности
- **Поддержка форматов списков:** Microsoft Word (`.docx`), Excel (`.xlsx`, `.xls`), `.csv`, `.txt`.
- **Поддержка фотоформатов:** JPG, PNG, WEBP, HEIC, а также профессиональные RAW-файлы (CR2, CR3, NEF, ARW, DNG).
- **Мгновенный старт:** Оптимизированный запуск интерфейса (< 1 сек) с фоновой асинхронной валидацией лицензии.
- **Быстрый сопоставитель:** O(1) поиск через хэш-индексы `Map` без зависаний.
- **Параллельный экспорт:** Копирование файлов пулом потоков в папки `Порт` (портрет) и `Мод` (модельное фото) в 5–10 раз быстрее обычного копирования.
- **Горячие клавиши оператора:**
  - `↑` / `↓` — выбор ученика в списке
  - `1` — назначить пол "Ұл / Мальчик" (с автопереходом)
  - `2` — назначить пол "Қыз / Девочка" (с автопереходом)
  - `E` / `У` — быстрое редактирование ФИО и номеров фото
  - `Esc` — закрыть окно
- **Автоматические обновления:** Проверка релизов и версий через Google Sheets API / GitHub Releases.

## 🔑 Лицензирование
Приложение привязано к аппаратному идентификатору устройства (`MachineGuid`), проверяется через защищенный Google Apps Script endpoint и поддерживает до 3 дней автономной оффлайн-работы.

## 🛠 Разработка
```bash
npm install
npm start
```
